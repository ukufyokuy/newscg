## 3. 目前專案架構

```
製作人提供：文稿（照片 HEIC/文字）＋ 配音（MXF 第1軌）＋ 素材（MXF/圖片）
   │
   ├─ ffmpeg：從 MXF 抽音軌 → vo.wav（48k 24bit）；抽素材畫面 → png
   ├─ whisper（Python，medium 模型）：逐字時間 → vo16.json（動作對齊依據）
   ├─ 網路查證：WebSearch/WebFetch、pdftotext（官方 PDF）、OpenStreetMap Overpass（真實地理）
   │
   ├─ Blender 5.1.2（無介面，Python 腳本）：
   │     build.py = exec(lib.py) ＋ 場景／字卡／運鏡／檢查
   │       -- build   → 存 scene.blend
   │       -- check N → 逐格自動檢查（安全框、互疊、字幕帶、人物瞬移、出框）
   │       -- stills  → 試算靜態圖
   │     Blender -b scene.blend -s A -e B -a（4 個程序平行算 PNG 序列）
   │
   ├─ numpy（Framework Python）：閃爍偵測、接縫比對、靜止收尾量測
   └─ ffmpeg：PNG ＋ vo.wav → MP4 預覽 ＋ XDCAM HD422 MXF（8 軌）
```

- 沒有前端、後端、App、雲端或 GitHub。全部在本機 macOS 以 CLI 執行。
- 沒有使用任何付費 API（不需要任何金鑰）。

## 5. 程式的重要邏輯

### 5.1 `lib.py`（共用元件庫；以 `鎮安動畫/CG1製作/lib.py` 為準，CG2、CG3、北一門、101 都是複製後改 `END_T`）
- 開頭解析 `ARGS = sys.argv[...]`。
  - `UHD = 'uhd' in ARGS`：4K 59.94p 開關，實際沒用到。
  - `FPS, FB = (60 if UHD else 30), 1.001`；`F(t) = int(round(t*FPS/FB))+1`（秒轉格號，29.97）。
  - `END_T` 決定 `FEND`。
- 材質 `mat(col, rough, emit, name)`：Principled BSDF 加 emission；`lin()` 做 sRGB 轉線性。
- 幾何：`empty`、`prim(name, mesh, loc, scale, mat, parent, rot)`、`boxr(x0,x1,y0,y1,z0,z1,m,parent)`；`UC/US/UCY/UCO/UTO` 是共用網格（立方體、球、圓柱、圓錐、環）。
- 文字：
  - `text()`：FONT 曲線，字型 `/Library/Fonts/DFHeiStd-W9.otf`（`FONT_B`）／`W7`（`FONT_M`）。
  - `t3d()`：立體大字，深色字面加淺色厚側面。
  - `tag2()`：黑底白字標籤。
  - `board()`、`btext()`。
- 🚨 `key_vis(o, intervals)`：顯示／隱藏鍵放在 **`F(t)-0.5`（半格）**，插值設 `CONSTANT`（`_const_hide`）。這是為了不讓動態模糊在第一格產生半透明殘影。`set_vis(root, ...)` 套用到 root 和所有子物件。
- 🚨 `counter3d(name, target, fmt, t0, dur, ...)`：`steps=None` 時每一格更新一次。數值 `target*(1-(1-u)^3)`，和長條、圓環用同一條緩動曲線。`fmt` 遇 0 回傳空白，不顯示「0」。
- 🚨 `bake_walk(p, pts, ...)`：逐格烘焙走路。**時間要夾住 `t=min(max(t,t0),t1)`**，否則起步格會誤選最後一段，造成瞬移閃爍（鎮安CG1 19 秒閃爍的根因）。
- `person()`／`teacher()`：Q 版人物，有五官、瀏海、識別證。`ghost()`：半透明缺額人偶。`pedestal()`、`swap()`、`pop()`／`unpop()`（彈出縮放，`s` 參數可指定縮放基準）。
- `studio()`：白棚，有磁磚地板 `floor` 和 `sun`，在 lib 結尾直接呼叫。

### 5.2 各支 `build.py` 的共同結構
1. `exec(open('lib.py').read())`
2. `grp(name, loc, t_on, t_off)`：文字群組，同時登記到 `TXT`。🚨 建完場景後要把**群組樞紐移到字的中心**（`for g_ in TXT: zc=平均子物件 z ...`），否則縮放彈出時字會從地板飛上來。
3. 場景物件與時間軸。所有時間都依配音逐字時間（`vo16.json`），要在註解標明「VO x.xx」。
4. 攝影機：
   - `RIG` 關鍵（`t, 中心x, 中心y, 注視高度, 方位角, 水平距離, 鏡頭高度, 焦距`），或直接用（位置＋注視點）。
   - 用 `pchip()` 插值，再做高斯時間平滑 `SIG=12*FPS/30`、`KR=3*SIG`。
   - 有硬切時：分段計算，平滑不跨切點；切點前後鍵設 `CONSTANT`，並在 `F_CUT-0.5` 補新段起點的鍵（避免切點第一格被動態模糊混在一起）。
5. 🚨 口白字幕空間：`_sub()` 轉換鏡位，距離 ×1.15～1.28，注視點下移約 0.10～0.12 倍可視高度。CG1、CG3 用 `RIG=[_sub(k) for k in RIG]`，CG2 是手調。
6. HUD 字卡：`HUD = empty((0,0,-1), parent=cam)`，`scale 0.1`。
   - 字和底板都放在鏡頭前 1 m。🚨 `clip_start` 必須小於 1，用 0.3 或 0.1。
   - 🚨 有開景深時，HUD 會被糊掉。解法二選一：關掉景深；或把 HUD 另外算成透明 PNG，再用 ffmpeg 疊上（CG3 的 `-- hud` 模式）。
7. 🚨 `-- check N` 逐格自動檢查（看到問題就 `bad += 1`）：
   - `EDGE`：字超出 8%～92% 範圍
   - `TOOBIG`：單一文字寬度超過 62%
   - `OVERLAP`：不同 root 的字互疊
   - `SRC`：字壓到資料來源
   - `SUBTITLE`：字或主體的 `world_to_camera_view` y < 0.22，也就是落進口白字幕帶
   - `JUMP`：可見人物相鄰兩格位移超過 0.6
   - `POPIN`：走入的人第一個可見格就在畫面內
   - 鎮安CG1 的車號標籤另有遮擋射線檢查（9×5 取樣）。
8. 算圖設定：
   - EEVEE，`taa_render_samples` 32～64
   - `view_transform='Standard'`（🚨 不用 AgX，會讓白棚變灰、顏色變淡）
   - 動態模糊開，`shutter 0.5`
   - 1920×1080，`fps 30/1.001`

### 5.3 交片前品質檢查（numpy，Framework Python）
- **閃爍偵測**：灰階縮成 192×108，`d=|f(i+1)-f(i)|` 取平均。若 `min(d[i-1],d[i]) > 3*|f(i+1)-f(i-1)|+1` 就判定為閃爍格。
- **大跳變**：`d>12`，要逐一確認是不是預期的切點或白閃。
- **局部重算接縫**：比對接縫前後的 `d`，要和鄰近格一致。
- **結尾段落感**：最後 40 格的動態量要遞減到接近 0。
- **字幕帶目視**：`ffmpeg drawbox=x=480:y=882:w=1330:h=72:color=red@0.35` 疊紅條，用 `tile` 拼成總表，親眼看。

```bash
# 抽配音與轉寫（不要把文稿放進 whisper prompt，會讓時間偏掉）
ffmpeg -v error -y -i 原始.mxf -map 0:a:0 -ar 48000 -c:a pcm_s24le vo.wav
ffmpeg -v error -y -i vo.wav -ar 16000 -ac 1 vo16.wav
whisper vo16.wav --model medium --language zh --initial_prompt "以下是台灣電視新聞的繁體中文報導。" --word_timestamps True --output_format json --output_dir .
# 量每軌音量（找配音在哪一軌）
for i in 0 1 2 3 4 5 6 7; do ffmpeg -nostats -i x.mxf -map 0:a:$i -af volumedetect -f null /dev/null 2>&1 | grep max_volume; done
# 響度
ffmpeg -nostats -i vo.wav -af ebur128=peak=true -f null - 2>&1 | sed -n '/Summary/,$p'

# Blender（B=/Applications/Blender.app/Contents/MacOS/Blender）
$B -b -P build.py -- check 1          # 逐格檢查，要看到 "CHECK DONE, problems: 0"
$B -b -P build.py -- stills 1.0,5.5   # 試算（50%）；加第三個參數 100 是全尺寸
$B -b -P build.py -- build            # 🚨 一定要確認輸出 "SAVED" 而且 scene.blend 時間有更新，才可以算圖
for r in "1 431" "432 862" "863 1293" "1294 1723"; do set -- $r; $B -b scene.blend -s $1 -e $2 -a > render_$1.log 2>&1 & done; wait
# 局部重算（只重算有改動的格；改了鏡頭要往前多算約 1.2 秒以上，並檢查接縫）
# 重算時若要覆蓋：--python-expr "import bpy;s=bpy.context.scene;s.render.use_overwrite=True;s.render.use_placeholder=False"

# 預覽 MP4
ffmpeg -v error -y -framerate 30000/1001 -start_number 1 -i renders/%04d.png -i vo.wav -c:v libx264 -preset slow -crf 16 -pix_fmt yuv420p -c:a aac -b:a 256k -shortest 名稱_預覽.mp4
# 正式 MXF（配音放第1軌，其餘7軌靜音；沒配音就8軌都用 anullsrc，並加 -t 秒數）
ffmpeg -v error -y -framerate 30000/1001 -start_number 1 -i renders/%04d.png -i vo.wav -f lavfi -i anullsrc=r=48000:cl=mono \
  -filter_complex "[0:v]format=yuv422p,setfield=tff[v]" \
  -map "[v]" -map 1:a -map 2:a -map 2:a -map 2:a -map 2:a -map 2:a -map 2:a -map 2:a \
  -c:v mpeg2video -pix_fmt yuv422p -b:v 50M -minrate 50M -maxrate 50M -bufsize 17825792 \
  -rc_init_occupancy 17825792 -flags +ildct+ilme -g 15 -bf 2 -intra_vlc 1 -non_linear_quant 1 \
  -dc 10 -qmin 1 -qmax 12 -lmin "1*QP2LAMBDA" -rc_max_vbv_use 1 -rc_min_vbv_use 1 \
  -c:a pcm_s24le -ar 48000 -shortest -f mxf 名稱.mxf

# 字幕帶紅條總表（交片前目視）
ffmpeg -v error -y -framerate 30000/1001 -i renders/%04d.png -vf "select='not(mod(n\,15))',drawbox=x=480:y=882:w=1330:h=72:color=red@0.35:t=fill,scale=384:-1,tile=6x8" -frames:v 1 sheet.jpg

# OSM（只有這台可用；查詢要小）
curl -s --max-time 150 -X POST https://overpass.private.coffee/api/interpreter --data-urlencode 'data=[out:json][timeout:100];way["building"](S,W,N,E);out geom tags;' -o bld.json
# HEIC → JPG
sips -s format jpeg -Z 2000 IMG.heic --out img.jpg
```

## 9. 使用者需求與規則（🚨 忘記就會做錯）

### 9.1 新聞正確性
1. 🚨 「做任何事都要先找資料、依真實現場做、要更周全」「我們是做新聞，不能錯，尤其是低級錯誤」「新聞台容錯率很低」。
2. 數字和事實要查官方一手來源，並交叉比對；查不到的標「示意」；資料互相矛盾時交給製作人決定。
3. 🚨 畫面上的字以製作人給的**文稿**為準。whisper 會聽錯：商借→商界、超鐘點→超中點、擇優→則又、教學節數→教學結束。製作人給文稿照片時要逐字核對錯字。
4. 製作人說「照我給的文字生、不要添加額外」時，畫面上只放他給的文字；查到的補充資料只在回報裡告訴他。
5. 台灣地圖：一定要小心，尤其縣市劃分，要照準則的七項檢查做。
6. 使用 Google 圖像要註明來源；OSM 照 ODbL 要求署名（但製作人說畫面上不放，要放片尾或素材清單）。
7. 政治題配色避開藍、綠（政黨聯想）。
8. 人物不要刻板印象（例如「退休」老師不要做白頭髮）；社會新聞人物可用無五官 Q 版；不呈現傷亡過程。

### 9.2 構圖與畫面
1. 🚨 **留口白字幕空間**：
   - 字幕列在 y=882–954 px（畫面高度 82–88%），中心偏右（x≈58–60%），最長一行 x 480–1810。
   - 所有字和主體都要在畫面上方 78% 以內（w2c y≥0.22），最下 22% 只放背景。
2. 🚨 **資料來源**：放下方，而且不能撞到字幕。準則與記憶的最新做法是「左側直排，或左下字幕帶上方」，不放右下角。是否要放資料來源，依每支的指示（例如 CG3 製作人說不用上）。⚠️ 矛盾說明：川習會那時製作人說「資料來源都放下方」，當時放在右下；學了口白空間後改成左側或左下字幕帶上方。以最新為準。
3. 畫面置中、主體不要太大也不要太邊界；字在 8%～92% 範圍內。
4. 一鏡到底（同一章節內不急停急起）；要有鏡頭運鏡，不要全部橫移；動作慢一點、看得舒服。
5. 字卡要清楚、有新聞專業感，不閃爍、不彈跳變形、不互疊。字要正對鏡頭。
6. 跑數字要符合數字邏輯：每格更新，和長條、圓環同步長，數字跟著長條頂端上升，最後停在正確值。百分比圖要精確，例如 99.58% 不能畫成全滿。
7. 結尾要有段落感：最後畫面不能還有人在走、鏡頭還在動，要全員到位、靜止收尾。
8. 人物要從合理的地方出場（例如從學校裡走出來），比例要和建築相符。
9. 質感：細膩模型、柔光；文稿標有 CG OUT／CG IN 時，要在該處乾淨硬切。

### 9.3 工作方式
1. 🚨 **「做完你自己要審視，不要有問題丟給我看」**：每支交片前都要自動檢查加親眼逐格審查。
2. 要搶快時，先交可用版本，但不能犧牲正確性。
3. 新文稿就從新文稿想（「不要參考舊的」），只沿用工具元件和規則。
4. 能自己做的就自己產生；免費可商用素材（Poly Haven CC0）下載前要先列出檔名、來源、大小，等使用者確認。
5. 每案寫成本回報到 `~/Desktop/成本回報/`，估計值和精確值要標清楚。
6. 回覆一律用繁體中文。
7. 4K 超過一小時就給 HD（1080）。

## 13. 重要設計決策

1. **用 Blender 腳本，不用手動 GUI**：可重現、可逐格檢查、能自動化。代價是每次都要寫程式。
2. **共用 `lib.py` 加各案 `build.py`**：元件集中，修一次（例如 `key_vis`、`bake_walk`、`counter3d`）就能複製到所有案子。⚠️ 目前是複製，不是 import。CG1 的 lib 最新，其他案子的 lib 是在不同時間點複製出去的。
3. **自動檢查（`-- check`）加 numpy 閃爍偵測加紅條目視**：回應製作人「自己審」的要求，三層把關。
4. **配音原樣放第 1 軌，不調響度**：那是記者的原始配音，由剪輯台決定混音。
5. **事件型還原的分寸**（北一門、101）：
   - 查不到來源的大傷亡事件，只做「模擬示意版」。
   - 不使用真實公司品牌做肇事情境。
   - 練習題用虛構航空，全程浮水印。
   - 地點可以用實景（使用者要求考「實地還原」）。
6. **口白字幕空間**：用統一的 `_sub()` 轉換舊鏡位，最省工；所有新案的鏡位一開始就要預留。
7. **CG OUT／IN 與事故章節用硬切，其他一鏡到底**：照準則和製作人的要求。
