**原則**
1. **背景＝主題「發生的地方」**：學校在教室，食品在廚房，稽查在廠房，車禍在現場。數據很抽象、找不到具體場所時，才用中性攝影棚。
2. **色調＝觀眾該有的情緒**：
   - 死亡沉重：去飽和
   - 管制冷硬：藍灰
   - 食物溫暖：暖色
   - 醫療潔淨：白
   - 解說中性：灰
3. **字色跟著背景**：淺色背景用深色字，深色背景用白字或黃字，紅色只留給重點和警示。
4. **色調可以在片中翻轉**：劇情從「表面」轉到「真相」時，舞台和色調跟著換（暖 → 冷、亮 → 暗），用物件飛起之類的動作連接（動畫11）。
5. **同類題材沿用同一種舞台**（例：稽查員都在鋼板廠房），形成公司的視覺一致性。
6. **檢討紀錄**：北大國小 v3 借用醫護類的淡紫白棚，學校題材其實更適合動畫23 的教室情境。

### 每看一支參考片的學習模板
1. **題材類型**：數據／社會快報／社會專題／生活消費專題／深度專題／其他；**背景（舞台）和色調是什麼，為什麼**
2. **結構**：分幾段，每段幾秒、講什麼
3. **運鏡**：一鏡到底還是分章節，用了哪些運鏡
4. **文字與標示**：字的樣式、標籤、圖示、配色、停留時間
5. **分寸與倫理**：怎麼處理傷亡、身分、品牌、未證實的事、平衡報導
6. **我可以直接套用的工具**：具體到能照著做，學完就填進上面的對照表

## 一、最高原則

1. **站在觀眾角度，依題材思考。** 參考片是學「怎麼想」，不是套模板。
2. **看得舒服、有吸引力，提供最好的視覺呈現。**
3. 每次算圖前自問：
   - 觀眾的視線會先落在哪裡？
   - 背景有沒有會分散注意力的東西？
   - 有沒有任何動作太快？
   - 每個字都讀得清楚嗎？

## 二、所有類型都要遵守

### 運鏡
- **同一章節內一鏡到底，不急停急起。** 段落之間靠運鏡和物件進出來轉換。只有專題類需要「換章節」時（例：動畫4 從「講人」切到「講經過」），才可以用一次硬切分段。
- **節奏寧可慢一點。** 彈出的回彈要輕（約 6%），數字跳動 1.2–1.8 秒，人物用正常步速（約 1.7 m/s）。
- **運鏡要有變化，不要全部橫移**：
  - 高處下降推近
  - 停留時緩慢環繞
  - 拉遠揭示
  - 推近
  - 升高俯瞰
  - 鏡頭跟著長高的長條往上升
- 每站的道具在鏡頭接近時才出現、離開後收起，背景保持乾淨。

### 文字
- 字要正對鏡頭，不可斜著讀，也不要放在遠處的看板上。
- 數字大、單位小（約 40%）；小標題用深色或紅色底加白字的標籤。
- **電視安全框**：所有文字都在畫面中央 90% 以內。用實際投影計算檢查，不靠目測。

### 構圖
- 每個畫面只講一件事，主體加一組大字，盡量置中，並填滿畫面。

### 質感
- 人物和建築要細膩，不可粗糙：
  - 人物：五官、眼睛高光、瀏海、識別證、服裝差異
  - 建築：欄杆細柱、窗框、門
- 開動態模糊和淺景深，柔和光影，主體和背景要分得開。

### 地圖（製作人再三強調：一定要小心錯誤，尤其縣市劃分）
每次使用台灣地圖都逐項檢查：
1. **資料來源**：只用內政部國土測繪中心在政府資料開放平臺發布的「直轄市、縣（市）界線」最新版，不自己描、不用來源不明的圖。
2. **行政區正確**：目前 **22 個**縣市（6 直轄市＋13 縣＋3 市）。2010、2014 年改制過（台中、台南、高雄縣市合併；台北縣升格新北市；桃園升格），舊圖會錯。
3. **縣與市分開**：
   - 嘉義市被嘉義縣包圍，新竹市和新竹縣相鄰
   - 標示嘉義縣時要把嘉義市挖空，不可整塊塗滿
4. **離島**：
   - 代表「全台」時，澎湖、金門、連江（馬祖）必須放進來（常用角落框）
   - 綠島、蘭嶼（台東縣）、小琉球（屏東縣）、龜山島（宜蘭縣）不可遺漏
   - 只講本島局部時可以聚焦本島
5. **事件定位用經緯度**：例如震央依中央氣象署（2023 年起不再叫氣象局）公布的經緯度放點，不可目測；標示的縣市要和公布的地點一致。
6. **簡化不出錯**：線條可以簡化，但縣市之間不能有縫隙或重疊，海岸輪廓要能辨認。
7. **交片前一定給製作人確認地圖。**
8. **製作人指示（2026-10-08）：以後所有台灣地圖一律用內政部國土測繪中心的資料**，畫面右下角加小字「地圖資料：內政部國土測繪中心」：
   - 位置在口白字幕帶下方、安全框內（右緣 x≈1820，y≈1000），墊半透明深色底，壓在陸地或海面上都看得清楚，也不能被地名標籤擋到。
   - 這是政府資料開放授權條款第1版的「顯名」要求，不標就不符合授權。
9. **現成資料**（不必每次重新下載）：`CG工具/台灣地圖_國土測繪中心/`
   - `county_1140318.json`：22 縣市多邊形，經緯度格式 `{縣市名: [[(經度,緯度),…],…]}`。
   - 原始 SHP 壓縮檔和 `shpread.py` 解析程式也在同一個資料夾。
   - **開工前先到 data.gov.tw/dataset/7442 看有沒有更新的版本**（檔名裡的數字就是版本日期）；有新版就重新下載並轉檔。
   - 壓縮檔裡的檔名是 Big5 編碼，用 Python zipfile 以 cp437→cp950 解碼後解壓。
10. **地點座標要查證**：基地、機場、地標的經緯度至少要兩個來源互相比對，不可憑記憶；查不到官方數字時要註明來源和誤差。
11. **示意要標明**：航線、待命區這類沒有公開座標的內容，畫面上要標「航線示意」之類的字樣，不可畫得像真實位置。

## 三、數據新聞（例：北大國小代理教師、IMG_3553/3554、動畫23/24）

- 場景用抽象白棚，或無縫地面淡出到背景（動畫20/21）。
- 文字用深色厚實立體字：
  - 字面深藍，重點數字用紅，強調用橙
  - 側面淺灰
- 「缺額、不在的人」用**半透明人偶**表示：
  - 淺藍灰色，透明度約 0.6
  - 零件不可互相透出
  - 保留深灰五官，一看就知道是人
- 「很多人」用成排或成群的人偶；比較兩個數字時並排，加深紅標籤（例：「差8倍」）。
- 數字要逐步跳動，圖表（長條、圓環）要和數字同步長出來。

### 人力不足／供需落差（例：動畫10 食品稽查員）
- **開場定性**：立體標題＋泡泡（例：「隱憂」），一開始就點出這是問題。
- **先講工作量，再講人力**：
  - 工作量：一群小模型代表數量（例：小工廠代表 13.5 萬家）＋黃色大字（抽驗 5.3 萬件次）
  - 人力：角色加身分標籤（中央、地方）＋人數（約 500 多名）
  - 兩者並列，缺口不用多說
- **國際比較**：
  - 國旗＋小人圖示＋橫條
  - 用同一把尺（例：每位稽查員負責多少人）
  - 橫條越長越吃緊
  - 國旗必須正確
- **資料年份要標出**：日曆小圖示（例：「107」）。
- **換算成「每人每天」**（動畫18）：
  - 例：每年稽查 253 萬次 ÷ 2195 人 → 平均一人查 4.6 案／天
  - 觀眾對「每人每天」最有感
  - 我驗算過：253 萬 ÷ 2195 ≈ 1,153 案／年，要再除以約 250 個**工作天**才會是 4.6；除以 365 天只有 3.2
  - 所以換算時分母（工作天還是日曆天）一定要和文稿一致，必要時標註
- **字型雙關**（動畫18）：「黑白兩道恐嚇」把「黑」做成黑底白字、「白」做成白底黑字，字本身就在說故事。
- **同一系列沿用同一舞台**（動畫10、18 都是鋼板廠房＋地方政府稽查員角色），觀眾一看就知道是同一個系列專題。
- **場景配合產業**：食品業就用廠房、倉庫貨架。

### 情境式數據專題（例：動畫9 老屋屋齡）
- **什麼時候用**：數據的主角就是某種場所（房子、街道、學校），就把數據放進那個場所，而不是抽象白棚。
- **路人視角**：一鏡到底，用眼睛高度在場景裡走，觀眾像自己走在街上。
- **數據放在實體載體上，一個載體一組數字**：
  - 牆面漆字（總量，數字跳動）
  - 建築看板（比例，30年以上 → 50年以上，上下疊放）
  - 店家招牌（縣市比較）
  - 施工立牌（政策條件）
  - 載體的質感要符合題材（老屋就用舊、髒、褪色的看板）
- **低角度往上拍**：讓建築顯得高大、老舊、有壓迫感。
- **觀眾替身角色**：Q 版人物背對鏡頭走進畫面，鏡頭跟在他身後看招牌。
- **暗示風險**：歪斜、破損的牌子加碎石。
- **資料來源全程掛著**：法規寫出全名和條件，不簡化。
- **字要清楚**：數字放大，鏡頭停下來接近正對載體，不可只斜斜掃過去（這是我北大國小 v1 失敗的原因）。

## 四、社會新聞

### 共同的「分寸」
- 死傷只用文字交代（「宣告不治」「受傷」），**不畫血、不畫傷者**，不渲染。
- 人物用卡通圓形頭像，不用真實照片；名字只寫姓氏（「吳姓兄弟檔」）。
- 每個人只交代三件事：**身分、年齡、傷勢**。
- 撞擊用一小團煙或紅色爆炸圖示，讓觀眾看懂就好，不製造驚嚇。
- **事實第一**：車種、顏色、車道、方向、碰撞順序要和警方或記者文稿一致。開工前列清單給製作人確認。

### 只有文稿時：現場還原三層法（最常見的情況）
多數時候沒有照片、沒有監視器畫面，只有文稿，必須想像並還原現場。畫面裡的每樣東西分三層處理：

| 層 | 內容 | 規則 |
|---|---|---|
| **事實** | 人、車數、車種、方向、誰撞誰、傷亡、時間、地點 | 只能來自文稿，不可自己編。文稿沒寫的關鍵事實（例：誰先闖燈、車速）不替它決定，改用中性畫法，不暗示責任。「疑似」要保留。 |
| **合理推定** | 車道數、路口形狀、單雙向、周邊環境、光線、天氣 | 從文稿用詞推定（「國道」→ 多車道加路肩護欄；「深夜」→ 夜間光線；「下雨」→ 濕路面）。有地名就查公開地圖（例：OpenStreetMap）確認實際格局。 |
| **美術** | 路旁建築、樹、天空、一般車流 | 可自由設計，但一律普通、不搶戲。用通用台灣街景，不出現真實店名或招牌，不讓背景暗示任何事。 |

- 開工前先交《現場還原表》：三層分欄，第二層附查證來源。製作人確認，或補上記者知道但文稿沒寫的細節後，才開始建模。

### 手法 A：全場景重建（動畫1）
- 寫實環境：路面紋理、樹、山、天空。
- 鏡頭跟著事件順序走：
  1. 交代所有當事者和排列順序
  2. 跟拍關鍵車輛
  3. 碰撞
  4. 逐一推近，交代每台車上的傷亡
  5. 以結論標籤收尾
- 文字用白字加深色陰影，結論用紅色圓角標籤（「無人傷」）。
- **多車事故**：每台車的車型和顏色都要不同，觀眾才不會搞混（動畫6）。
- **常駐事件資訊卡**（動畫17）：左上角整支都在，包括日期（日曆圖示）、時間（紅底）、國道編號加方向加公里數（例：「國道1號南下83.5K」）、最近交流道（例：「湖口交流道」）。位置資料必須照文稿或警方資料。
- **營業車輛標業者名稱**（動畫17）：報導有寫出的客運、貨運業者，名稱標在車上（例：「和欣客運」）；私家車不標身分。
- **隧道事故**（動畫19）：
  - 暗、低調的隧道光，只有路面和車亮，壓迫感自然出來
  - 救護車或警車在車陣中鑽行，表現救援困難、交通回堵
  - 鏡頭從車陣上方低空掠過，最後停在關鍵車輛（大貨車）正面
  - 整支沒有任何文字，推測是交給剪輯台疊字；接案時要先問製作人「CG 要帶字還是乾淨版」
- **連環撞依序呈現**（動畫17）：每次撞擊各自一個爆炸圖示、依序出現，鏡頭沿著車列跟過去，讓觀眾看懂撞擊順序。
- **軌跡線加距離**（動畫6）：
  - 在路面畫出從撞擊點到停止位置的箭頭線
  - 沿著線寫距離（例：「彈飛50公尺」）
  - 字平貼在路面上，跟著線的方向
- **傷者說明卡**（動畫6）：
  - 對話框形式，白底黃框，尾巴指向那台車
  - 層級：小標籤（國籍或身分，例：「港籍」）→ 粗體（姓氏、關係、年齡）→ 小字（傷勢）
  - 結果另外用橘紅標籤（例：「送醫不治」）
  - 卡片依序彈出
- **停留時間依字數決定**：
  - 字多時鏡頭完全靜止，給足閱讀時間（動畫6 最後停約 12 秒）
  - 字少時可以很快（動畫5 每段約 1.5 秒）

### 手法 B：實景照片 + 浮空路段（動畫2）
- 背景用真實現場照片，調淡、柔焦（白霧感），讓觀眾認出地點。
- 3D 只做相關路段，像浮在照片上的立體模型，從遠處飛近。
- 鏡頭從車尾跟拍，再繞到側面看清碰撞。
- 碰撞用紅色鋸齒爆炸圖示，結論用深紅底黃字標籤（「釀17人傷」）。
- 需要記者提供現場照片。

### 手法 D：街景實拍照片 + 3D 物件（動畫25，並實際重做練習）
- **和手法 B 的差別**：照片不調淡，直接當成完整的真實畫面；3D 車輛和人偶要對齊照片透視，看起來像真的放在那條路上。
- **講「原因」**：例：黃字加黑描邊「視線被前車和A柱擋住」，箭頭指向視線被擋的位置。不只是重建撞擊，還要解釋為什麼會撞。
- 行人用半透明青色無臉人偶，倒地也只是人偶躺下，不呈現傷勢。
- 動作標籤（「轉彎」「加速切進車道」）跟著車輛移動。
- **做法**（`CG工具/photo_composite.py`）：
  - 鏡頭高度、焦距、俯仰角對齊照片的地平線和消失點
  - 地面設為「陰影捕捉」，只接收 3D 物件的影子
  - Cycles 算出透明背景圖層，再用 ffmpeg 疊到照片上
- **練習學到的**：
  - 有沒有落地陰影，決定 3D 物件是「站在路上」還是「貼在照片上」
  - 尺寸要對照照片裡的參考物（路燈、斑馬線、原有行人）
  - Blender 5 的合成節點寫法改了，改用 ffmpeg 疊圖最穩
- **製作人確認（2026-10-03）**：公司會使用 Google 街景／Google 地圖畫面，**一定要標來源**（例：「資料來源：Google」）。
- **版權注意**：動畫25 的底圖是 Google 街景截圖，畫面角落有 Google 年份和地圖標記。使用街景要符合 Google 的授權與標示規定，或改用記者自己拍的現場照片。開工前先確認底圖來源。

### 重大新聞現場還原（動畫30 普悠瑪6432次出軌）
重大事故的 CG 是「全國觀眾第一次理解發生什麼事」的畫面，要求最高。

**開工第一步：先查真實地理位置（製作人指正：普悠瑪我第一次把車站位置、月台方向都做錯）**
1. **查地圖**：用 OpenStreetMap（免費、不必登入）抓現場周邊的真實座標：鐵軌／道路線形、彎道方向與半徑、車站／站房位置、周邊道路、河川、建物。用這些座標直接生成場景，不憑想像搭建。畫面標「地圖資料 © OpenStreetMap 貢獻者」。
2. **查官方報告**：出軌或撞擊位置、方向、翻覆節數、時間、人數。
3. **查現場畫面**：新聞照片、空拍、參考 CG，確認月台在哪一側、地標（天橋、站房、河流）在哪裡。
4. **三方對照**：地圖、報告、照片要一致。不一致時列給製作人判斷，不自己挑一個。
- 普悠瑪實例：地圖顯示車站**就在半徑約 305 公尺的彎道中間**（所以叫半弧型車站），站房和月台在**彎道內側（南側）**，旁邊是平行的中山路二段；列車往**外側**翻。我第一版把月台和站房放在外側、車站放在彎道後段，全都錯了。

**精髓：鏡頭是「站在現場的目擊者」（製作人指正：我第一次沒學到運鏡）**
| 秒數 | 運鏡 | 用意 |
|---|---|---|
| 0–2 | 站在月台，慢慢經過站名牌，軌道空無一物 | 先交代地點與「出事前的平靜」 |
| 2–8 | 貼軌道高度在車頭旁往後看，車身呼嘯而過 | 觀眾感受速度 |
| 9–11 | 鏡頭在月台等，列車迎面逼近 | 壓迫感 |
| 12–16 | 低角度，車頭朝鏡頭傾倒、滑過鏡頭前 | 事故衝著觀眾來 |
| 17–21 | 側翻車廂塞滿前景，沿軌道慢推 | 像親身走過現場 |
| 22–23 | 從殘骸上方升起 | 由地面過渡到全景 |
| 24–31 | 空拍掠過真實地景，停在站名牌 | 只在最後看全貌；開頭結尾都落在站名牌，首尾呼應 |

- **鏡頭幾乎都在地面眼睛高度**，一直在動、但動得有目的（跟拍 → 等待 → 走過 → 升起）。
- **前景要有東西**（柱子、月台、車廂）掠過，畫面才有景深與真實感。
- **字幾乎沒有**，只有「366乘客」和時間；不要用標籤把畫面變成圖表。
- 我的第一版用了數據新聞的思維（高空俯視＋一堆標籤），車廂像玩具，災難的份量完全出不來。**題材決定鏡頭語言：重大事故＝沉浸式地面視角；數據新聞＝環繞式展示。**

**結構：照事件時間軸走一遍**
1. **身分**：列車開出，車身側面立起大字「普悠瑪 6432次 366乘客」（車種、車次、人數）。
2. **時間**：沿途空中浮出時間（數字時鐘）。
3. **關鍵時刻**：列車以正面朝鏡頭駛進車站前的彎道，揚起煙塵 → 出軌翻覆。
4. **現場全貌**：鏡頭從低處拉高到空拍，車廂呈 Z 字形散落在軌道上，周邊農地、道路、樹林、河道都在。
5. **地點定錨**：最後停在真實站名牌「新馬車站」，旁邊標時間。

**做得好的地方**
- **寫實程度最高**：車輛塗裝、月台、天橋、電車線架、周邊地形都照實際做，因為觀眾會拿真實新聞畫面來對照。
- **車廂最後的位置和形狀要對照空拍或官方資料**（Z 字形翻覆），這是重大事故最受檢視的地方。
- **節制**：沒有乘客、沒有傷者、沒有血，也不用誇張特效；煙塵只是一小團。災難本身已經夠沉重。
- **配色不刻意加戲**：晴天、自然光照實呈現，不額外渲染悲劇氣氛。

**我做這類新聞時的額外規定**
- 車次、人數、時間、站名、車廂數和翻覆位置，全部對照官方公布（交通部、台鐵、調查報告）或記者確認，列進事實核對表。
- 原因未確定前不畫「為什麼出軌」（例如速度數字），只畫「發生什麼」。
- 寫實模型（列車、車站）需要素材時，照素材原則先問製作人。
- **實作教訓（普悠瑪女聲版）**：第一版只依配音做示意，結果彎道半徑（120 → 官方 306 公尺）、彎道轉向、出軌位置（官方「尚未進入月台」）、傾覆方向（官方「向外側」）、傾覆節數（官方「4 節」）全都和官方不符。**重大事故開工前必須先查官方調查報告**（監察院、運安會、行政院報告），把可查到的事實列成表，再建場景；查不到的（例如各節精確停放位置）才用示意並標明。
- 車號和「前進方向第幾節」可能不同（普悠瑪：前進方向第1節＝第8車），畫面標示要和文稿用詞一致。

### 酒駕、撞上執勤警方（動畫28）
- **先交代現場原本的狀態**：警車、警用機車停在快車道，員警（藍色人偶）和民眾（青色人偶）站在旁邊。觀眾先看懂「這裡本來在處理事情」，接著廂型車才從後方駛來撞上。
- **用人偶顏色區分身分**：藍色＝警察，青色＝民眾。同樣是無臉人偶，顏色一換，身分就分清楚了。
- **酒駕證據分兩層**：
  - 現場觀察用藍底白字標籤（「酒氣甚濃」「醉到無法言語」）
  - 檢測數值用橘色圓角大標籤（「酒測值達1.01」），數字是最有力的證據，所以最後出現、最醒目
- **數值一定照文稿**：酒測值的單位（mg/L）要和文稿一致，文稿沒寫單位就不自己加。

### 手法 C：路口事故快報（動畫5，6 秒）
- **先讓觀眾看懂路口**：鏡頭從高空俯視慢慢降低、傾斜，路口格局（斑馬線、人行道、周邊建築）一目了然。
- **路名放在路面上，跟著道路方向**：南北向直排（例：「文心路」），東西向橫排（例：「文心南五路」），白字加深色描邊。
- **每台車一個標籤，講清楚路權**：
  - 例：「綠燈直行」「違反號誌左轉」
  - 黑底白字，每個標籤 4～6 個字
  - 標籤跟著車子移動
- **關鍵字變色**：只把關鍵動作改成黃字（例：「違反號誌**左轉**」），視線直接落在重點上。
- **爆炸圖示裡直接寫結果**：黃色爆炸圖示內寫紅字「2車相撞」。
- **短片節奏**：每段約 1.5 秒、只講一件事、字數極少，6 秒也能讀完。
- **方向箭頭加目的地**（動畫13）：路面上長出紅色大箭頭，箭頭裡寫目的地（例：「台北」），比「北上／南下」更直覺。
- **鏡頭跟著做動作的車**（動畫13）：例如轉彎的砂石車，鏡頭跟著它繞，兩車相對路線自然看懂。
- **中性動詞描述碰撞**（動畫13）：例：「騎上前 對撞」，只描述動作，文稿沒說責任就不暗示責任。
- **人物用無臉白色人偶**，地面材質暗示環境（例：黃土＝工地、郊區）。

### 社會專題（動畫4）：先講人，再講事
- **說故事的順序和社會新聞相反**：社會新聞先重建經過、最後交代傷亡；社會專題先讓觀眾認識受害者，再交代事件怎麼發生。
- **分章節**：
  - 第一章講人：靜態、長時間停留（約 15 秒），文字逐行出現，讓觀眾消化。
  - 第二章講經過：跟拍重建。
  - 章節之間可以用一次硬切。
- **車內 X 光俯視圖**：
  - 拿掉車頂，從正上方呈現每個座位坐了誰
  - 乘客用淡色人偶，罹難者只用不同顏色區分，不描繪傷勢
  - 旁邊依序列出：總人數、傷勢分布，以及罹難者的身分、年齡、狀況，最後加深紅標籤（例：「一屍兩命」）
- **地點交代**：空中方向牌（例：「內埔→萬丹」）＋路面上的立體路名（例：「大學路」）。
- **因果鏈條文字放在路面上**：動機 → 行為 → 結果，跟著透視、跟著車走，例如「不想被擋住 → 疑似試圖超車 → 車速快 打滑撞進民宅」。
- **用字謹慎**：還沒確定的原因一律加「疑似」，不替司法下結論。

## 四之二、新聞專題：生活消費類（例：動畫7「粉飾美味 精算食安」）

- **標題可以玩雙關**：例如「粉飾」＝掩飾＋湯底粉。標題做成立體物件放在場景裡開場，背景可以加一個淡淡的巨大關鍵字（「粉」）。
- **場景配合題材**：餐飲題材就用廚房後場、紙箱、粉袋，觀眾一眼知道在講哪一行。
- **A 與 B 並排比較**：兩種做法放在同一舞台左右對照，造型和道具一致，只有「做法」不同。
- **把數量畫出來**：例：「1萬5千cc → 20鍋」，就真的冒出 20 個鍋。
- **抽象感受用視覺比喻**：「自然甘甜」用彩虹，「熬6小時」用火加蒸氣。
- **數字字樣**：橘紅色立體字加白邊，放在對應的物件上。
- **結論用最強的字**：紅色方塊字逐字落下（例：「成本差4倍」，數字特大）。
- **平衡報導**：一定給被批評的一方說話，用對話框標明身分（例：「用粉業者：……」）。
- **不點名品牌**：只寫身分類別（「連鎖火鍋店」），人物用卡通角色。

## 四之三、新聞專題：健康醫療／科普類（例：動畫8「化學合成物」）

- **從真實走進身體**：
  - 開場用真人實拍（例：喝湯）
  - 臉上浮出白色網格線，像被掃描，轉成 CG
  - 鏡頭穿進體內
- **沿著路徑走**：鏡頭跟著主角物質移動（嘴 → 食道 → 胃 → 腸），結構就是過程本身的順序。
- **看不見的東西具體化**：
  - 物質用彩色幾何形狀代表，每個拉細引線標學名（小字，不搶主角）
  - 胃酸、細菌畫成可愛的擬人角色，身體內部的畫面不噁心、不嚇人
- **風格可以漸變**：從立體寫實過渡到平面插畫（腸道段），只要運鏡連續就不突兀。
- **效果用圓形泡泡說明**：問句一行、結果一行（例：「難分解?／腸胃好菌變少」）。
- **未定論的健康說法一律加「?」**，不把推論講成事實，也不製造恐慌。和社會新聞的「疑似」是同一個精神。

## 四之五、調查報導：追物流和金流（例：動畫15 假再利用）

- **開場暗示**：書桌、製圖板、打問號的回收標誌，暗示「被設計出來的計畫」。標題可用台語雙關和真假對比（「擺係假? 假再利用 真毀環境」）。標題後可以硬切一次。
- **微縮模型世界**：整個體系攤在一個平台上（源頭工廠 → 道路 → 處理廠 → 最終去處），觀眾一眼看懂全貌。
- **鏡頭跟著物料或金錢走**：路線就是故事。
- **源頭先講危害**：廢料種類用白色立體字標示，危害用紅色警示框（例：「含重金屬 不淨化恐生戴奧辛污染」）。
- **金流**：
  - 公事包裝錢，加單價標籤（例：「5元/噸」「220元 循環經濟推廣費」）
  - 各方用告示牌標身分
- **邏輯質疑框**：「若真……何須……」，把報導的推理攤給觀眾看。
- **證據**：放大鏡加標籤（例：「香蕉萎縮」「蚯蚓死亡」），只寫觀察到的現象，不誇大。
- **算總帳**：黑板算式，兩方角色在旁，最後紅色定論標籤（例：「無本暴利」）。
- **具名原則**：有報導事實根據的才具名（例：中聯），其餘匿名（例：A處理廠）。

### 微縮世界 vs 圓形轉台：怎麼選（對照動畫15、動畫20）
| | 微縮模型世界（動畫15） | 圓形轉台（動畫20） |
|---|---|---|
| 適合 | **地點很重要**：東西從哪裡運到哪裡（工廠 → 農地） | **步驟很重要**、地點不重要：一道道處理程序 |

## 四之六、金額揭露：黑板算錢（例：動畫22 不法利得，並實際重做練習）

**原片好看的原因**
1. **背景牆用題材本身的材質**：整面爐碴碎石牆。抽象的算錢畫面，背景仍在提醒「這是廢料的錢」。
2. **配色極度節制**：綠黑板、木框、白色金屬大數字，只有「不法利得」一個紅色。
3. **算式用動作演出來**：「7億元」飛出一疊鈔票 → 變成「6億元＋1億元」。
4. **一次只多一樣東西**：碎石落下 → 公事包 → 數字 → 角色＋身分牌 → 紅章。

**實際重做學到的（`CG工具/chalkboard.py`，練習圖在 `CG工具/練習/`）**
- 數字和單位要依數字的實際寬度排版，單位約數字的 1/3 大、對齊數字底部；用固定座標會一下空太開、一下疊在一起。
- 黑板約佔畫面 2/3，四周要露出背景牆，否則牆的材質沒有作用。
- 程序紋理的比例要配合物件尺寸，不然紋理會被拉成一團糊。
- 物件前後關係要檢查（我把公事包蓋子放到黑板後面，結果完全看不到）。
- **限制**：程序生成的碎石牆再怎麼調，還是像花崗岩，做不出原片那種真實粗糙的爐碴質感。寫實材質需要照片貼圖（例如 Poly Haven、ambientCG 的免費可商用素材，下載前先問製作人），或使用公司的素材庫。

## 四之七、校園題材：教室舞台（例：動畫23 營養師，並實際重做練習）

**原片的優點**
1. **背景教室輕微柔焦**：黑板、時鐘、木課桌只交代「這是學校」，不搶前景。
2. **暖色調**：米白牆、暖木課桌、自然光，有學校的生活感。
3. **大量人數用米白色無五官剪影人群**（180萬孩童），單色、簡單，數量感強又不雜亂。
4. **前景字加白色描邊和陰影**：壓在複雜背景上仍然讀得清楚。
5. **最嚴重的一條換色放大**：台北、台中藍色，新北紅色加黃色大字「近8000」。
6. **對照法規**：「超過法定 一人顧40班」，最後用紅底白字問句「怎嚴謹把關」。

**實際重做學到的（`CG工具/classroom.py`，練習圖 v1～v3）**
- 沒加描邊的字壓在教室背景上，又淡又糊；**加白色外擴描邊＋偏移陰影**後立刻跳出來。這是寫實或複雜背景上的必要做法。
- 冷灰色的教室像倉庫，換成暖色牆、木地板、窗光後才像學校。
- 鏡頭推太近會裁到字（v2 失敗），**每次改鏡頭都要重跑安全框檢查**。
- 紅底按鈕上的字要用白色，不可以沿用其他地方的深色字。
- **還不足的地方**：我的 Q 版角色是幾何方塊拼的，比不上原片乾淨的卡通角色；原片在「1:」旁還有小人物圖示。角色要做到原片水準，需要正式建模，或公司現有的角色模型。

## 四之八、兩國／兩地比較（例：動畫24 台日比拚，並實際重做練習）

## 四之九、物件本身就是圖表（例：動畫26 營養午餐經費，並實際重做練習）

**原片的優點**
1. **主角物件孤立在淡藍漸層背景中央**：學生課桌加營養午餐餐盤，一眼看出是「學校午餐」，背景乾淨，沒有任何干擾。
2. **比例長條直接長在桌緣**：100 → 紅 30（人事廚具設備）／綠 70（菜肉食材）。圖表就是物件的一部分，不另外放圖表。
3. **類別標籤用小掛勾吊在桌下**，像真的掛在課桌上，很有物件感。
4. **政策改變＝長條移動**：高雄的營養師出場舉牌「嚴謹把關」，長條從 30/70 滑到 25/75。
5. **配色**：紅色＝被分走的錢，綠色＝真正吃進肚子的錢，顏色本身就有好壞的意思。

**實際重做學到的（`CG工具/object_bar.py`，`desk_30.png` 對 `desk_25.png`）**
- **物件比例要對**：一開始做成長方餐桌，不像學生課桌；改成方正比例才對味。
- **俯視角度約 50°**：同時看得到桌面上的餐盤和桌緣的長條。
- **AgX 色彩轉換會把淺藍背景洗成灰色**：淺色背景要用 Standard 轉換，才保得住顏色。
- **吊牌字要夠大**：桌下吊牌在 1080p 畫面上至少約 30px 高，我的字還偏小。
- **還不足**：程式做的食物（色塊和圓球）遠不如原片寫實的炸雞、薯條、青菜，需要寫實食物模型或貼圖。

## 四之十、日曆、菜單、時間表（例：動畫27 營養午餐菜單，並實際重做練習）

**原片的優點**

## 四之十一、成分累加：配方揭密（例：動畫31 化工醬油，並實際重做練習）

**原片的結構（19 秒，一鏡到底）**
1. **標題躺在工廠地面上**：「無豆泡出來的 化工醬油」，背景是貨架、紙箱、原料袋，冷調的工廠內部。
2. **推進到主角攪拌鍋**：機身側面印紅色直排「真假醬油揭密」。
3. **添加物一瓶瓶加入**：糖、鹽、焦糖色素、甜味劑（醣精）、修飾澱粉、調味劑、防腐劑（苯甲酸鈉），每瓶都從鍋口上方擠進鍋裡。

**優點**
- **配方是「加出來」的，不是「列出來」的**：瓶子越疊越多，觀眾直接感受到「這醬油裡沒有黃豆，全是添加物」。
- **瓶子排成扇形、同一面朝鏡頭**：瓶身往外張、瓶口收向鍋心，每瓶的字都清楚；瓶色對應成分（焦糖色素用褐色、防腐劑用灰色）。
- **專有名詞放小字**：例如「防腐劑」下面加「苯甲酸鈉」，大字給一般觀眾看，小字給想深究的人看。

**實際重做學到的（`CG工具/ingredient_pour.py`，`pour_70.png` 到 `pour_200.png`）**
- 瓶子圍著鍋口放射狀排列（v2、v3）會互相遮擋，字也會轉到背面。**要學原片排成同一面朝鏡頭的扇形**（v4 才對）。
- **實心物件會把裡面的東西蓋住**：醬汁放在實心鍋體裡面看不到，又被實心鍋緣蓋住，要放到鍋面上方才露得出來（v5 修正）。
- 成分清單集中寫在程式最上方的 ITEMS，照文稿填；每 0.8 秒加一瓶，可依配音調整。

## 四之十二、成長趨勢：圖示環跟著數字長大（例：動畫32 露營熱潮，並實際重做練習）

**原片的結構（16 秒）**
1. 標題「遠離都市 200萬人瘋露營」配帳篷圖示，下方小字「資料來源：露營協會」。
2. 中央圓台出現大數字並開始跳動（605 → 815，2012 年），旁邊藍色圓形年份徽章；帳篷沿著圓台圍成一圈。
3. 數字跳到 1800（2017 年），**外面再長出一圈帳篷、圓台變大**：成長是「看得到的面積」。
4. 外圍升起橘色圖釘，標出消費類別：高檔帳篷、睡袋、食材消費、露營車。
5. 最後深紅立體卡片「每年破25億」，黃色大數字。

**優點**
- **休閒題材用淡薄荷色的清新世界**，配小樹點綴，和揭弊類的冷暗色完全相反。
- **年份徽章緊貼數字**：觀眾永遠知道這是哪一年的數字。
- **成長同時用兩種方式呈現**：數字跳動，加上圖示環的面積變大。
- **先講規模（幾家），再講錢（消費類別 → 總額）**，層次清楚。

**實際重做學到的（`CG工具/growth_ring.py`，`ring_815.png` 對 `ring_1800.png`）**
- **圖示數量要依數據比例**：每 60 家一頂帳篷，815 → 14 頂、1800 → 30 頂，由程式計算，不是隨便放。
- **數字格式照文稿**：我一開始自動加了千分位（1,800），原片和文稿寫 1800，要一致。
- **貼在傾斜面上的字要沿著那個面的法向量往外推**，否則會陷進物件裡看不到（圖釘上的字改了兩次）。
- 還不足：圖釘上的字偏小；最後的「每年破25億」卡片還沒做進工具。

## 四之十三、航照年份對比：土地被開發的過程（例：動畫33 濫墾營區，並實際重做練習）

## 四之十四、標註元件：事實、批評、感嘆、引述各有樣式（例：動畫34 營養午餐 17 元，並實際做成元件庫）

**原片的結構（21 秒）**
1. 學生餐廳一排排課桌，鏡頭推近其中一張桌上的餐盤；標題「食材17元怎撐!」旁邊接雲朵泡泡「偏鄉孩何辜」。
2. 菜上逐一冒出標註：
   - 菜名用**白字**直接躺在菜上（咖哩、紅燒）
   - 批評用**紅底白字標籤**，帶尖角指向那道菜（重口味壓新鮮度、加工品、蔬食日降成本、便宜水鯊魚 90元/公斤）
3. 餐盤清空，換成第二個案例「嘉義朴子市 食材17元」：肉絲蛋炒飯、薯條、冬瓜魚丸湯，菜名用小白字。
4. 鏡頭往下帶，一張**真實菜單卡**滑進來當證據（嘉義民雄鄉**某國小**、10月16號、一餐18元，附菜色照片），學校匿名。
5. **黃色鋸齒爆炸框**放引述與誇張數據：「能飽就好」「卡路里爆表700卡」。

**四種標註，四種意義（以後統一照這個用）**
| 樣式 | 用途 | 例 |
|---|---|---|
| 白字黑邊 | 中性事實、名稱 | 咖哩、紅燒 |
| 紅底白字＋尖角 | 批評、問題（指向對象） | 重口味壓新鮮度 |
| 白色雲朵泡泡 | 感嘆、提問 | 偏鄉孩何辜 |
| 黃色鋸齒爆炸框 | 引述的話、驚人數據 | 能飽就好 |

**實際做成元件庫學到的（`CG工具/callouts.py`，任何場景都能套用）**
- **標籤要夠大**：原片紅標籤約佔畫面寬度的 1/5。我第一版太小，鏡頭推近、字放大後才有原片的力道。
- **標籤高低錯開**：同一高度的標籤會黏成一長條，要前後高低錯開。
- **多行標籤的底框高度要跟著字的實際高度算**（「蔬食日／降成本」兩行）。
- 雲朵和爆炸框放在畫面上緣時容易被切掉，要留在安全框內。

## 四之十五、各縣市比較：黑板粉筆塗繪（例：動畫35 午餐價格亂象，並實際重做練習）

2. 縣市形狀用**粉筆斜線從左往右塗滿**，像老師現場畫；台北和新北合在一起畫、一起標名。

**優點**
- **黑板＋粉筆＝「解說、算給你看」的口吻**，和教育題材一致。

## 四之十六、兩方逐級比較：雙向箭頭比較列（例：動畫36 大學教授年薪，並實際重做練習）

**原片的結構（33 秒，鏡頭固定在暖色教室前）**
1. 黑板上寫標題「大學教授年薪」；資料來源寫在粉筆槽上，整支都在。
2. 兩個角色站到黑板左右，各掛名牌「台灣大學」「香港中文大學」。
3. 一列一列出現**雙向箭頭橫幅**：左白框「110萬」← 中間藍字「助理教授最初級」→ 右白框「477萬」。
4. 舊的列**淡出**，換下一組：助理教授最高級 → 副教授最高級 → 教授最高級。
5. 最後一列的右值下方出現紅字「5.28倍」。

**優點**
- **左右站位＝兩方**：左邊數字屬於左邊的人，觀眾不用看名牌就知道。
- **中間寫比較基準（級別）**，確保比的是同一個等級，比較才公平。
- 一次只放一兩列，舊列淡出，畫面永遠不擠。
- 只在最後標倍數：前面讓觀眾自己感受差距，最後一句話收尾。

**驗算紀錄**：四組倍數分別是 4.34、4.15、4.76、5.28 倍，原片標的 5.28（951÷180）正確。
- 注意：原片只標最大的倍數。如果文稿是說「最多差到 5.28 倍」沒問題；若文稿說「差 5 倍以上」，就要確認每一級是否都符合（其實最低只有 4.15 倍）。**畫面上的倍數說法要和文稿的措辭一致。**

**實際重做學到的（`CG工具/compare_rows.py`）**
- **倍數由程式從兩個數值算出**，四捨五入後再驗算一次才放上畫面，不手打。
- **列要在黑板上垂直置中**：第一版全擠在上方，下半部空空的。
- **角色站在黑板前、壓住黑板邊緣**，畫面才有前後層次（原片也是這樣）。

## 四之十七、出處當道具：證據書（例：動畫37 大學排名，並實際重做練習）

## 四之十八、從文稿到畫面：逐句搭配法（製作人要求「給你文稿，你要會生成適合的搭配」）

拿到文稿後，**每一句**都問同一組問題，填進搭配表：

| 欄位 | 要決定什麼 |
|---|---|
| 這句的資訊類型 | 出處／母數／排名／比較／金額／過程／原因／結論／引述／感嘆 |
| 對應的視覺手法 | 查下方「資訊類型 → 手法」對照 |
| 畫面上的字 | 只取關鍵詞和數字，照文稿原字，不改寫 |
| 標註樣式 | 事實白字／批評紅標籤／感嘆雲朵／引述爆炸框／定論蓋章或紅框 |
| 運鏡與停留 | 依字數決定停留秒數 |

**資訊類型 → 手法對照（從 37 支參考片歸納）**
| 文稿裡的資訊 | 適合的畫面 | 參考 |

| 營養、健康建議（食物成分、每日建議量） | 淡灰白抽象背景＋發光圓台；先基準（每日建議量），再份量（寫明條件），再換成日常食物，最後建議；排名用圓形徽章、主角加框 | 動畫42、8 |

| 政策、證件、制度內容介紹 | 證件做成實體當舞台，角色站在內頁上；特點用同樣式緞帶標籤往下疊；標籤收掉後蓋章總結；深藍底＋中央光暈 | 動畫41、37 |

| 排名、名單 | 書頁或清單逐字打出，順序跟配音 | 動畫37 |

## 四之四、量化比喻：數量大到難以想像（例：動畫14 轉爐石）

## 五、深度專題（例：動畫3「你的露營區安全嗎？」）

- **專題識別條**：左上角固定一條專題標題（藍綠色條＋圖示），從頭到尾都在。
- **地理開場**：用衛星實景（Google Earth）從高空俯衝進目標區域，先建立「在哪裡」。
- **資訊分三層，逐層展開**：
  1. 大標題（紅色立體字，數字特大）
  2. 說明（《》括號白字）
  3. 拆解（縣市標籤＋數字）
- **字立在地形上**：立體字跟著實景地形的透視一起動，鏡頭飛到哪個地點，那裡的資訊才浮出來。

- **真實照片佐證**：照片做成卡片插入；涉及特定業者時名稱要打碼（例：半X灣），避免點名爭議。

- **製作方式**：
  - 在 Google Earth Studio 規劃飛行路徑，輸出影格、3D 攝影機資料、地點標記
  - 匯入 Blender 對齊攝影機，把立體字放在指定經緯度
  - 合成識別條、照片卡和來源標示

### 動作音效（2026-10-09 起，製作人要求「動畫每個動作帶音效」）
