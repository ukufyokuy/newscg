# 新聞專題配樂規則

> 核心原則：**新聞的專業感優先，地方風格只是點綴。**
> 觀眾要感覺到「這是一則嚴謹的新聞專題」，然後才隱約察覺「這是土耳其」。

## 一、配樂的角色

1. 配樂是**輔助敘事**，不能搶走旁白、受訪和現場音的注意力
2. 觀眾看完不應該特別記得配樂，只記得內容和情緒
3. **有好的現場音時，現場音優先**（熱氣球噴火、市集叫賣、渡輪汽笛、咖啡沖煮聲），配樂要讓位或停下來

## 二、地方風格怎麼加：點到為止

- 主體用**新聞專題常見的編制**：鋼琴、弦樂鋪底、柔和的合成器長音、輕微的節奏脈動
- 地方元素**一次只加一種**，而且只當點綴，例如：
  - 旋律裡偶爾出現一兩個當地音階的特色音（例如希賈茲音階的半音）
  - 一個當地樂器的音色輕輕帶過（撥弦、框鼓輕拍）
- 地方元素主要放在**片頭、空景、轉場**，有旁白的段落要收斂
- 份量參考：**地方色彩大約只佔一兩成**，大部分時間聽起來就是專業的新聞配樂
- **避免刻板印象**：不用誇張的中東轉音、肚皮舞節奏、觀光宣傳片式的異國風情

## 三、依題目調整情緒

| 產出 | 情緒方向 | 避免 |
|---|---|---|
| TV1 卡帕多奇亞地景保育 | 開闊、穩定、溫暖，帶一點對自然的敬畏 | 太夢幻、像旅遊廣告 |
| TV2 LÖSEV 公益村莊 | 溫柔、克制、帶著希望 | **悲情催淚的鋼琴**、煽情 |
| TV3 綠色觀光救通膨 | 中等速度的節奏脈動，理性、略帶張力 | 太緊張、像財經快報 |
| L 網路長版 | 比電視輕快，有旅行感，但保持質感 | 像業配、像網紅 vlog |
| S 直式短版 | 節奏較快，前 3 秒要有明確的開場重音 | 從頭到尾同一種節奏、沒有起伏 |

## 四、混音與音量

- **有人聲時，配樂比人聲低約 15–20 dB**；空景、轉場時才拉回來
- 受訪者講到關鍵句時，配樂不要在這時候下重拍或轉段
- 整體音量：
  - 網新影片：約 −16 LUFS（依網新交片規範）
  - 電視專題：依公司播出規範（台灣電視常用 −24 LKFS，以公司規定為準）
- 配樂要**跟著剪接點收尾**，不能突然切斷；換段落時用交叉淡化

## 五、不能做的事

- 不在旁白底下用**有歌詞**的音樂
- **不把宗教聲音當配樂**（例如清真寺的喚拜聲）；現場自然收到的可以當現場音，但要尊重、不剪成節奏
- 不用知名歌曲或可以被認出的旋律
- 悲傷或嚴肅的段落不用輕快的音樂
- 不用來源不明的音樂

## 六、版權與紀錄

- 來源：**公司授權曲庫**或**自己用程式合成的原創配樂**都可以用（已確認：電視專題可以使用程式合成的配樂）
- 每支片交片時附**配樂表**：時間碼、曲名或檔名、來源、用途（鋪底、轉場、片頭）
- 程式合成的配樂，保留產生它的程式和參數，方便之後修改
