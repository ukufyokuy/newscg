## 要請雄獅確認的事

1. **有頂大市集 12/13 是星期日**，一般星期日不營業。是否改到其他天，或改去香料市集？
2. **L2 的米其林綠星餐廳**不在行程表上，是哪一家？哪一天去？
3. **安卡拉只有 LÖSEV 一站**，企劃提到的「首都經濟」沒有時間拍，要不要調整企劃？
4. TV1 需要的**地景管理單位或保育專家受訪**，有沒有安排？
5. TV3 需要的**飯店業者、在地居民、經濟數據受訪**，有沒有安排？
6. **記者簽證、器材入境、空拍許可**請土航和雄獅協助確認。
