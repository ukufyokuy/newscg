# 年輪與光 — 老去的 3DCG

以心理學觀點表現「老去不是單向的衰退，而是重新理解自己、重新整理生命的過程」的即時 3D 短片（72 秒，循環播放）。

- `index.html`：Three.js 即時 WebGL 版本，由觀看者的顯示卡即時算繪（含 Bloom 光暈）。用瀏覽器開啟即可。
- `aging-3dcg.mp4`：1280×720、24fps 的預先算繪影片。

## 四個章節
1. **不是單向的衰退**：一條向下墜的光線，在低處轉彎成上升的螺旋。
2. **重新理解自己**：球體表面浮現年輪般的紋路（外表的改變），核心卻越來越亮。引 Erikson「自我統整 vs. 絕望」。
3. **重新整理生命**：數百個記憶碎片中，少數重要的被留下、環繞核心，其餘淡去。引 Carstensen「社會情緒選擇理論」。
4. **學會調整心態**：核心沉為種子，長出樹；葉子轉金、飄落後化成上升的光。
